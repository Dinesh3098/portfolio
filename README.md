# Dinesh Bhadane — Portfolio

Personal portfolio of Dinesh Bhadane, Senior Backend Engineer.

Built with vanilla HTML, CSS, and JavaScript — no frameworks, no build step.

## Structure
- `index.html` — all sections (About, Skills, Projects, Experience, AI, Blog, Contact)
- `styles.css` — design system and layout
- `script.js` — loader, cursor, animations, counters
- `images/` — project screenshots
- `favicon.svg` — site icon

## Local preview
Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
# then visit http://localhost:8000
```

Deployed on Cloudflare Pages.
